Run configuration

Values resolve in a fixed order: built-in validated defaults, then a configuration file, then explicit overrides. Leaving a field alone uses the default that reproduces the validated COMP702 pipeline. The resolved configuration below — not the input file — is what a run executes and what is written to provenance.

BRI and duplicate detection

Validated default: 0.001 Å. Changing this creates an experimental scientific configuration.

Validated default: 0.010 Å.

Validated default: 0.010 Å, inclusive.

These are three distinct concepts. Representation precision p is the grid complete BRI is represented on — it is not a duplicate threshold. Brain filtering threshold bounds the lossless prefilter; Brain is used only for filtering. Complete-BRI threshold τ is the final, inclusive near-duplicate criterion, and final duplicate classification is always based on complete-BRI L∞.

Each threshold must be an exact whole number of representation units on the configured grid, so it can never be silently rounded. At the validated p = 0.001 Å one unit is 1 mÅ and τ = 0.010 Å is 10 units.

Bronze / Silver / Gold

LayerContents
Bronze Immutable source inventory for the selected snapshot: PDB ID, S3 key, compressed size, ETag, manifest timestamp. No scientific filtering happens in this layer.
Silver The deterministic parsed representation. Intentionally not persisted: it is reconstructed from the immutable Bronze object identity by the versioned parser, so the archive is not copied twice.
Gold Scientifically derived outputs: accepted and rejected chains, geometric validation, complete BRI, Brain, candidate pairs, complete-BRI distances, classifications, representative mapping, removed-chain audit and the final retained-chain release.

Canonical pipeline

Prerequisites are lettered, not numbered, so they are never mistaken for scientific stages. Stages 3 and 4 share one producer, as do Stages 8 and 9; both canonical identities are shown because they are distinct scientific concepts. Stages 14a–c are engineering subdivisions of scientific Stage 14. Stages 11–13 are investigation and validation passes and are never a deletion relation.
