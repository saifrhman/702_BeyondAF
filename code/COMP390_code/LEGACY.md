# LEGACY — COMP390 historical work

This directory holds Minhao's COMP390 dissertation work: OpenFold inference
demos, checkpoints, environment exports, batch scripts and results, together
with the original task scripts and their backups.

**It is retained deliberately and in full.** Nothing here has been deleted,
moved or rewritten by the COMP702 productisation work, and nothing here should
be deleted.

## Status

* **LEGACY.** It is not part of the current COMP702 PDBClean pipeline.
* It is not executed by any current entry point.
* Its paths, environments and node assumptions are historical and are not
  maintained.

## Relationship to the current work

Under the project's authority order, this material is the *lowest* authority:
current executable code and generated manifests outrank it, as do the frozen
Git commits, the project's explicit decisions, and the current documentation.
Use it as a historical record of what was done in COMP390, not as a description
of what the current pipeline does.

For the current pipeline, see `docs/ARCHITECTURE.md` and the README.
